# ⚡ JavaScript - Warm up

Bienvenue dans le projet **JavaScript - Warm up** ! Cet ensemble d'exercices est un échauffement conçu pour se familiariser avec la syntaxe de base de JavaScript, manipuler les variables, les structures de contrôle (boucles et conditions), ainsi que les fonctions de base avant de plonger dans des concepts plus avancés.

---

## 📚 Objectifs d'apprentissage

À la fin de cet échauffement, les concepts suivants doivent être maîtrisés :
* **Syntaxe de base** : Déclaration de variables avec `let`, `const` et `var`.
* **Structures conditionnelles** : Utilisation de `if`, `else if`, `else` et des opérateurs logiques.
* **Boucles** : Maîtrise des boucles `for`, `while` et de la manipulation des index.
* **Fonctions** : Déclaration, passage de paramètres et valeur de retour (`return`).
* **Sortie console** : Utilisation de `console.log()` pour afficher des informations et déboguer.

---

## 📋 Exigences et Contraintes

* **Interpréteur** : Les scripts sont généralement exécutés avec **Node.js** (version 18+ recommandée).
* **Style de code** : Le code doit respecter les normes de style standard (par exemple, conformité avec `semistandard` ou `eslint` si demandé).
* **Rigueur** : Attention aux types de données (chaînes de caractères, nombres) et à l'utilisation du mode strict (`"use strict";`) si requis.

---

## 📁 Structure du projet

Voici la liste des scripts d'échauffement inclus dans ce dépôt :

| Fichier | Description |
| :--- | :--- |
| `0-javascript_is_amazing.js` | Affiche "JavaScript is amazing" dans la console. |
| `1-3_languages.js` | Affiche trois lignes distinctes sur les langages appris. |
| `2-arguments.js` | Gère les arguments passés en ligne de commande (`process.argv`). |
| `3-value_argument.js` | Affiche le premier argument reçu ou un message par défaut. |
| `4-concat.js` | Concatène deux arguments passés en paramètre. |
| `5-to_integer.js` | Convertit un argument en entier (si possible) avec `parseInt`. |
| `6-multi_languages_loop.js` | Affiche plusieurs lignes en utilisant un tableau et une boucle. |
