Bienvenue sur Mon Application Flask

Ceci est une application Flask simple utilisant les templates Jinja.

Flask est un framework web WSGI léger. Il est conçu pour faciliter et accélérer le développement, tout en permettant de passer à des applications plus complexes.

Fonctionnalités de cette application :

  • Framework Flask
  • Templates HTML
  • Moteur de templating Jinja
  • Composants réutilisables
  • Pages multiples
